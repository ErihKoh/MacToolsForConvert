#                                  MacToolsForConvert
Інструкція зі встановлення та використання
Версія 0.1.0 • macOS • Українська мова
## 1. Про проєкт
MacTools — настільний застосунок для macOS для роботи з файлами та їх конвертації між форматами, які підтримують реалізовані конвертери.

###   Поточні можливості:
- додавання окремих файлів і рекурсивне додавання папок;
- фільтрація файлів за категоріями та перегляд інформації про вибраний файл;
- конвертація підтримуваних зображень, зокрема HEIC і HEIF;
- перетворення PDF на зображення та створення PDF із зображень;
- конвертація DOCX, RTF і TXT між підтримуваними парами форматів;
- конвертація DOCX у PDF через LibreOffice;
- пакетна конвертація, вибір вихідного формату й папки результатів;
- вибір вихідного формату та папки для збереження результатів;
- відображення прогресу конвертації та повідомлень про помилки.

  
## 2. Системні вимоги
- Комп’ютер Mac із macOS.
- Python 3.12.
- Доступ до термінала та інтернет для встановлення Python-залежностей.
- LibreOffice для конвертації DOCX у PDF;
- FFmpeg для конвертації відео.
Python-бібліотеки встановлюються через requirements.txt. LibreOffice та FFmpeg встановлюються окремо.  

## 3. Встановлення на macOS
   
### 3.1. Перевірка Python

У терміналі виконайте:

``` python3.12 --version ```


Очікується Python 3.12.x. Якщо Python 3.12 не встановлено, установіть його з офіційного сайту Python або через Homebrew.

### 3.2. Отримання проєкту

Якщо проєкт зберігається у Git-репозиторії, клонуйте його, підставивши адресу свого репозиторію:

``` git clone <URL_РЕПОЗИТОРІЮ> ```

Перейдіть до кореневої папки MacToolsForConvert. Якщо проєкт передано архівом, розпакуйте його та відкрийте відповідну папку.

### 3.3. Створення та активація віртуального середовища

```
python3.12 -m venv .venv 
source .venv/bin/activate
```

Перевірте, що середовище використовує потрібну версію Python:

``` python --version ```

### 3.4. Встановлення залежностей

```
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
```

Якщо конфліктів немає, pip повідомить: “No broken requirements found.” Файл requirements.txt містить Python-бібліотеки; системні програми встановлюються окремо.

## 4. Встановлення та перевірка FFmpeg

FFmpeg використовується для конвертації відео.

Якщо FFmpeg ще не встановлений, на macOS з Homebrew його можна встановити командою:

```
brew install ffmpeg
```
Перевірте версію:

```
ffmpeg -version
```
Перевірте наявність утиліти ffprobe, яка використовується для отримання інформації про відеофайли:

```
ffprobe -version
```
Перевірте шляхи до виконуваних файлів:

```
which ffmpeg
which ffprobe
```
У поточному середовищі Apple Silicon стандартний шлях Homebrew зазвичай починається з `/opt/homebrew/bin/`.
Якщо FFmpeg встановлений в іншому місці, перевірте, як саме застосунок визначає шлях до нього, перш ніж змінювати конфігурацію.

## 5. LibreOffice

LibreOffice потрібен для конвертації DOCX у PDF. Його потрібно встановити окремо з офіційного сайту: https://www.libreoffice.org/download/download-libreoffice/

### Поточна конфігурація очікує виконуваний файл за шляхом:

```
/Applications/LibreOffice.app/Contents/MacOS/soffice
```

### Перевірте наявність файла та версію:

```
ls -l /Applications/LibreOffice.app/Contents/MacOS/soffice
/Applications/LibreOffice.app/Contents/MacOS/soffice --version
```

Якщо LibreOffice не встановлено, застосунок може запускатися, але конвертація DOCX у PDF буде недоступна. Якщо програму встановлено в іншому місці, потрібно змінити 

`LIBREOFFICE_PATH` у `src/config.py`.

Системна утиліта `textutil`, яку використовує конвертер документів, постачається з macOS і має бути за шляхом 

`/usr/bin/textutil`.

## 6. Запуск застосунку

У корені проєкту з активованим середовищем виконайте:

`python main.py`

Має відкритися головне вікно MacTools. Щоб завершити роботу, закрийте вікно.

## 7. Основні принципи використання

- додавайте окремі файли або папки. Для папок застосунок рекурсивно знаходить файли у вкладених папках.
- використовуйте категорії, щоб фільтрувати список файлів.
- виберіть файл, щоб переглянути доступну інформацію про нього.
- виберіть вихідний формат і папку для збереження результатів.
- запустіть конвертацію та стежте за прогресом і повідомленнями про помилки.
- доступні вихідні формати залежать від типів вибраних файлів і сумісності конвертерів. Файли з категорій “Файли”, “Медіа” або “Архіви” не обов’язково можна конвертувати.
- стежте за прогресом та повідомленнями про помилки.

Доступні вихідні формати залежать від вибраних файлів і сумісності конвертерів.

Наявність файлу в категоріях «Файли», «Медіа» або «Архіви» не означає, що його формат можна конвертувати.

Збереження результатів

Застосунок має уникати перезаписування наявних файлів призначення. Перед конвертацією перевіряйте вибрану папку та назви результатів.

Не видаляйте оригінали, доки не переконаєтеся, що результати конвертації коректні.

## 8. Підтримувані формати

### 8.1. Зображення

Поточний ImageConverter підтримує:
* JPEG — .jpg, .jpeg
* PNG — .png
* WebP — .webp
* TIFF — .tif, .tiff
* BMP — .bmp
* HEIC — .heic
* HEIF — .heif
Конкретні перетворення залежать від зареєстрованих конвертерів і підтримуваних форматів.
Для читання HEIC/HEIF використовується Python-бібліотека pillow-heif.

HEIC і HEIF підтримуються як вхідні формати. Вихідні формати залежать від зареєстрованих конвертерів.
### 8.2. PDF

PDFConverter підтримує PDF → PNG, PDF → JPEG, а також підтримувані зображення → PDF.
Для багатосторінкового PDF кожна сторінка зберігається окремим зображенням у спеціальній папці.

### 8.3. Документи

Документний конвертер працює з DOCX, RTF і TXT. Для перетворень між цими форматами використовується системна утиліта textutil. Для DOCX → PDF потрібен LibreOffice.

### 8.4 Відео
Відеоконвертер використовує FFmpeg та підтримує такі вхідні розширення:

* MP4 — .mp4
* MTS — .mts
* M2TS — .m2ts
* MOV — .mov
* MKV — .mkv
* AVI — .avi
* WebM — .webm
* MPEG — .mpeg, .mpg
* TS — .ts
* 3GP — .3gp

Поточний вихідний формат — MP4.

Залежно від кодеків вхідного файлу конвертер може копіювати сумісні аудіо- та відеопотоки або кодувати їх у сумісні формати.

Наявність підтримуваного розширення не гарантує успішної конвертації будь-якого файлу: результат також залежить від кодеків, пошкодження файлу та можливостей FFmpeg.

## 9. Папки результатів і тимчасових даних

### Папка результатів за замовчуванням:

`~/Documents/MacTools`

### Папка тимчасових даних:

`~/Library/Caches/MacTools`

Ці шляхи визначені у src/config.py. Перед конвертацією застосунок перевіряє вхідний файл, сумісність форматів і наявність файла призначення. Наявний файл призначення не повинен перезаписуватися.

## 11. Розв’язання типових проблем

Python 3.12 не знайдено

`python3.12 --version`

Установіть Python 3.12 і перевірте, чи доступна команда в терміналі.

Не знайдено requirements.txt

```
pwd
ls
```

Переконайтеся, що ви перебуваєте в корені проєкту, де розташовані main.py, requirements.txt і папка src.

Помилка встановлення залежностей

```
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

Не знайдено LibreOffice

```
ls -l /Applications/LibreOffice.app/Contents/MacOS/soffice
```

Якщо файла немає, установіть LibreOffice або оновіть LIBREOFFICE_PATH у `src/config.py`.

Не знайдено textutil

`ls -l /usr/bin/textutil`

Ця системна утиліта має постачатися з macOS.

Застосунок не запускається

```
python --version
python -m pip check
python main.py
```

Перегляньте повний текст помилки в терміналі.
