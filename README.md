# MacToolsForConvert

**MacTools** — настільний застосунок для macOS, призначений для конвертації зображень, PDF-документів, текстових документів, відео, аудіо та електронних книг.

Застосунок створений на Python і PySide6. Він працює локально на комп'ютері та використовує зовнішні інструменти для окремих операцій конвертації.

## Основні можливості

- Графічний інтерфейс на PySide6.
- Додавання файлів через перетягування або вибір у файловому діалозі.
- Пакетна конвертація декількох файлів.
- Автоматичне визначення доступних форматів конвертації.
- Відображення інформації про вибрані файли.
- Підтримка декількох категорій файлів.
- Збереження оригінальних файлів.
- Захист від перезапису наявних файлів.
- Тимчасове створення результатів перед їх публікацією.
- Обробка помилок і обмеження часу виконання зовнішніх процесів.

## Підтримувані формати

### Зображення

Вхідні формати:
- JPG / JPEG
- PNG
- WebP
- TIFF / TIF
- BMP
- HEIC / HEIF

Вихідні формати:
- JPG / JPEG
- PNG
- WebP
- TIFF / TIF
- BMP

Для обробки зображень використовується Pillow, а для HEIC/HEIF — pillow-heif.

### PDF

Підтримувані операції:
- Зображення → PDF.
- PDF → PNG.
- PDF → JPG / JPEG.
- Обробка багатосторінкових PDF із збереженням сторінок як окремих зображень.

Для роботи з PDF використовується PyMuPDF.

### Текстові документи

Підтримувані формати:
- DOCX
- TXT
- RTF

Можливості:
- DOCX ↔ TXT
- DOCX ↔ RTF
- TXT ↔ RTF
- DOCX → PDF

Конвертація текстових документів виконується через системну утиліту macOS `textutil`.

Для DOCX → PDF використовується LibreOffice.

### Відео

Вхідні формати:
- MP4
- MTS
- M2TS
- MOV
- MKV
- AVI
- WebM
- MPEG
- MPG
- TS
- 3GP

Вихідний формат:
- MP4

Для конвертації використовується FFmpeg та ffprobe.

Відео перекодовується у H.264, аудіо — в AAC, якщо початкові потоки не відповідають умовам копіювання без перекодування.

### Аудіо

Підтримувані формати:
- MP3
- WAV
- FLAC
- M4A
- AAC
- OGG
- OPUS

Підтримується конвертація між переліченими форматами.

Для обробки аудіо використовується FFmpeg та ffprobe.

### Електронні книги

Вхідні формати:
- FB2
- EPUB
- PDF

Вихідні формати:
- FB2
- EPUB

Підтримувані операції:
- FB2 → EPUB
- EPUB → FB2
- PDF → EPUB
- PDF → FB2

Для конвертації використовується Calibre.

**Примітка:** PDF із відсканованими сторінками може потребувати OCR. Вбудоване розпізнавання тексту не передбачене.

## Технології та залежності

Основні технології:
- Python 3.12
- PySide6 — графічний інтерфейс.
- Pillow — обробка зображень.
- pillow-heif — підтримка HEIC/HEIF.
- PyMuPDF — робота з PDF.

Зовнішні системні інструменти:
- FFmpeg — відео та аудіо.
- ffprobe — аналіз медіафайлів.
- Calibre — конвертація електронних книг.
- LibreOffice — конвертація DOCX у PDF.
- macOS textutil — конвертація текстових документів.

## Встановлення середовища розробки

### Вимоги

- macOS.
- Python 3.12.
- Homebrew — для встановлення зовнішніх інструментів.

Перевірка версії Python:

```bash
python3.12 --version
```

### Клонування репозиторію

```bash
git clone <repository-url>
cd MacToolsForConvert
```

### Створення віртуального середовища

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

### Встановлення Python-залежностей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Встановлення зовнішніх інструментів

FFmpeg:

```bash
brew install ffmpeg
```

LibreOffice:

```bash
brew install --cask libreoffice
```

Calibre необхідно встановити окремо з офіційного сайту:

https://calibre-ebook.com/download

`textutil` входить до складу macOS.

Застосунок використовує системні шляхи до зовнішніх інструментів, визначені в конфігурації проєкту.

## Запуск застосунку

З кореневої папки проєкту:

```bash
source .venv/bin/activate
python main.py
```

## Використання

1. Запустіть MacTools.
2. Додайте файли перетягуванням у робочу область або через кнопку вибору.
3. Виберіть потрібні файли.
4. Виберіть вихідний формат.
5. Запустіть конвертацію.
6. Перегляньте результат у папці призначення.

Доступні формати залежать від вибраних файлів і наявності необхідних зовнішніх інструментів.

## Збереження файлів

За замовчуванням результати конвертації зберігаються в:

```text
~/Documents/MacTools
```

Кеш застосунку:

```text
~/Library/Caches/MacTools
```

Оригінальні файли не змінюються. Якщо файл із таким ім'ям уже існує в папці призначення, застосунок не перезаписує його.

## Усунення несправностей

**Не працює конвертація відео або аудіо**

Перевірте встановлення FFmpeg та ffprobe:

```bash
ffmpeg -version
ffprobe -version
```

**Не працює конвертація електронних книг**

Переконайтеся, що Calibre встановлений і доступний за шляхом, зазначеним у конфігурації.

**Не працює DOCX → PDF**

Перевірте встановлення LibreOffice та шлях до виконуваного файла `soffice`.

**Не працює конвертація текстових документів**

Перевірте доступність системної утиліти:

```bash
/usr/bin/textutil -help
```

**Не відкриваються HEIC/HEIF**

Перевірте встановлення Python-залежності `pillow-heif`.
